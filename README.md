## Cook master

A modern Android app for discovering, browsing, and exploring recipes. Users can search 
for recipes by ingredients, view recipe details, and interact with a clean, responsive interface.

## Features
* Ingredient Search: Select ingredients you have and find matching recipes.
* Recipe List: Display recipes in a grid or list format with images.
* Recipe Details: View full recipe instructions, ingredients, and preparation steps.
* Favorites: Save favorite recipes using Firebase Firestore.
* Navigation: Smooth navigation between fragments using Safe Args.
* Asynchronous Operations: Fetch recipes and handle data using Kotlin Coroutines.
* Clean UI: Responsive design with RecyclerView, GridLayoutManager, ViewBinding, and Material components.

## Technologies used
* Kotlin – Main programming language
* MVVM Architecture – Model-View-ViewModel
* Coroutines & Flow – Asynchronous programming
* Retrofit + Moshi – Networking and JSON parsing
* Hilt – Dependency Injection
* Firebase Firestore & Authentication – Favorites syncing
* Safe Args – Type-safe navigation between fragments
* RecyclerView & GridLayoutManager – Dynamic lists and grids
* ViewBinding – Safe UI binding
* Material Components – Modern Android UI
